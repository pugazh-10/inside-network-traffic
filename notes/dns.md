# DNS Analysis Notes

## What is DNS?

DNS (Domain Name System) translates domain names into IP addresses.

## Observation

While capturing traffic using Wireshark, multiple DNS queries were generated when accessing Google services.

## Key Findings

- DNS resolves domain names to IP addresses.
- DNS activity occurs before website communication.
- DNS traffic helps analysts understand communication patterns.

## Security Relevance

DNS monitoring can help identify suspicious domains, malware communication, and unusual network activity.
