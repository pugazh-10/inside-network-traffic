# TCP Handshake Analysis Notes

## What is TCP?

TCP is a reliable communication protocol used for data transmission.

## Observation

TCP connections were established using the three-way handshake process.

## Key Findings

- SYN starts communication.
- SYN-ACK acknowledges the request.
- ACK completes the connection.

## Security Relevance

Understanding TCP communication helps identify abnormal network behavior and troubleshoot connectivity issues.
